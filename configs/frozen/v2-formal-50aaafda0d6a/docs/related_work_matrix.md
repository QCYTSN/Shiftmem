## Positioning boundary

The sources establish that language agents can store reflections, trajectories, messages, or skills; drift detectors can signal changes; and inventory control under hidden nonstationarity has a mature model-based literature. The comparison motivating ShiftMem is narrower: whether an LLM inventory agent can retain auditable natural-language experiences while conditionally suspending and revalidating them when public operating conditions change. The formal experiments, not this matrix, determine whether that design improves outcomes.
